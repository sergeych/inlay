# Roadmap

Available: source-bearing PNG editing, executable renderers, live local Mermaid,
source recovery, examples and a portable AI skill.

Available in the Writer extension: native diagram objects with their own source and
preview storage, external editing, Undo/Redo, and source-bearing PNG import/export.
ODT viewing and preservation without the extension are verified. See the integration
README for installation and supported boundaries.

Next: broader LibreOffice/platform coverage, richer editor integration and qualified
interchange beyond ODT.

Possible later work: richer CLI creation/import, syntax highlighting, SVG support,
additional renderers and verification on more desktop platforms. These are directions,
not implemented features.
